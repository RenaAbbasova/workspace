# Coursework: Albañiles Digitales – Software Builders

My exercises and projects from the **Albañiles Digitales – Software Builders** program (605 hours, September 2024 – February 2025),
organised by the Servicio Navarro de Empleo (Nafar Lansare) with Veridas. The program is in Spanish. The folder structure and
some exercise material come from the course template; the solutions and projects are mine.

## What is inside

| Folder | Topic |
|---|---|
| `introduccion-programacion` | Introduction to programming |
| `core-javascript` | The foundations of the language |
| `html` | HTML and CSS, including the **final project of the module** |
| `networking` | The border between frontend and backend (course notes) |
| `core-node` | Node.js for the server |
| `express` | Web services with Express, the backend library |
| `client` | Client-side JavaScript without libraries |
| `cloud` | Amazon Web Services: virtual infrastructure (course notes) |
| `agile` | Good practices: agile (course notes) |

## Final HTML and CSS project

[`html/ProyectoFinal_HTML_CSS`](html/ProyectoFinal_HTML_CSS): a website for a friend's actor-representation business, with a home page,
about page, actors, casting profiles, a contact form, a login and a WhatsApp button.

## Other work from the same program

- [Api_Plugin_Generator](https://github.com/RenaAbbasova/Api_Plugin_Generator): a Next.js app that generates WordPress, Chrome and Firefox plugins.
- [Data_Api_Fetcher_Extension](https://github.com/RenaAbbasova/Data_Api_Fetcher_Extension): a Chrome extension that fetches data from three public APIs.
